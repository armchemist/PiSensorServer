# 리니어 스테이지 (스텝모터 + 볼스크류)

라즈베리파이 GPIO로 스텝모터 드라이버에 펄스를 보내 캐리지를 mm 단위로 움직인다.

| 파일 | 역할 |
| --- | --- |
| `pulse_test.py` | 배선 확인용. 200펄스만 보내 조금 움직여 본다 |
| `stage.py` | mm 단위 제어. 소프트 리밋 포함 |

## 배선

라즈베리파이 GPIO → 스텝모터 드라이버 (BCM 번호 기준).

| 드라이버 | 파이 GPIO | 비고 |
| --- | --- | --- |
| `PUL+` (펄스) | `GPIO 22` | |
| `DIR+` (방향) | `GPIO 27` | |
| `ENA+` (활성) | `GPIO 17` | 안 쓰면 `stage.py` 에서 `None` 으로 |
| `PUL-` `DIR-` `ENA-` | `GND` | 공통 접지 |

⚠️ **모터 전원(24V)이 라즈베리파이 쪽에 닿으면 파이가 즉사한다.** 배선 후
전원을 넣기 전에 24V 계통과 파이 계통이 분리돼 있는지 반드시 확인할 것.
공통으로 묶는 것은 GND뿐이다.

## 준비

```bash
sudo apt update
sudo apt install -y pigpio python3-pigpio
sudo systemctl enable --now pigpiod
```

파이썬으로 GPIO를 직접 토글하면 리눅스 스케줄링 때문에 펄스 간격이 흔들려
모터가 덜덜거린다. `pigpio` 는 DMA로 파형을 만들어 타이밍이 안정적이다.

## 설정값

`stage.py` 상단을 하드웨어에 맞게 고친다.

| 상수 | 의미 | 예 |
| --- | --- | --- |
| `LEAD_MM` | 볼스크류 1회전당 이동 거리 | 1605=5, 1610=10, 1620=20, 1204=4 |
| `MICROSTEP` | 드라이버 분주 설정 | 드라이버 딥스위치와 일치시킬 것 |
| `STEPS_PER_REV` | 모터 1회전 스텝 수 | 1.8도 모터 = 200 (고정) |
| `INVERT_DIR` | 방향이 반대면 `True` | |
| `STROKE_MM` | 스테이지 유효 스트로크 | 소프트 리밋 기준 |

## 사용

먼저 `pulse_test.py` 로 배선을 확인한다.

```bash
python3 pulse_test.py
```

| 결과 | 판단 |
| --- | --- |
| 캐리지가 조금 움직임 | 정상 |
| 소리만 나고 안 움직임 | 드라이버 전류 설정이 낮거나 모터선 순서 문제 |
| 아무 반응 없음 | GND 연결 확인 (가장 흔한 원인) |
| 반대로 움직임 | `stage.py` 의 `INVERT_DIR = True` |

확인되면 mm 단위로 움직인다.

```bash
python3 stage.py
```

```python
from stage import move_mm, move_to_mm, position_mm, set_position_mm

move_mm(10, speed_mm_s=5)   # 정방향 10mm
move_mm(-10)                # 역방향 10mm
move_to_mm(50)              # 절대 위치 50mm
print(position_mm())
```

처음에는 `speed_mm_s=5` 정도로 느리게 시작하고, 안정되면 조금씩 올린다.
갑자기 고속을 주면 탈조(스텝 씹힘)가 나면서 멈춘다.

| 모델 | 최대 속도 (매뉴얼) |
| --- | --- |
| -1605 | 50 mm/s |
| -1610 | 100 mm/s |
| -1620 | 200 mm/s |
| -1204 | 40 mm/s |

## ⚠️ 리미트스위치가 없다

현재 구성에는 끝단 감지 센서가 없어서, **소프트웨어만이 스테이지의 끝을 안다.**

- `STROKE_MM` 범위를 벗어나는 이동은 `SoftLimitError` 로 거부한다
- 시작 위치는 `START_POSITION_MM`(기본: 스트로크 중앙)으로 **가정**한다.
  전원을 넣기 전에 캐리지를 손으로 돌려 중앙에 두고 시작할 것
- 이동 중 중단되면(Ctrl+C 등) 몇 펄스가 나갔는지 알 수 없으므로 위치를
  미상으로 표시하고, `set_position_mm()` 으로 다시 알려주기 전까지 이동을 거부한다

테스트 중에는 항상 전원 플러그 근처에 손을 두는 것이 좋다. 여유가 되면
리미트스위치를 다는 편이 안전하다(스테이지에 장착 구멍이 있다).

## 구현 메모

펄스는 `pigpio` 의 wave API로 만든다. `set_PWM_frequency()` 는 요청 주파수를
샘플레이트 기준 이산값으로 스냅시키기 때문에, 요청값으로 계산한 시간만큼
기다리면 실제로 나간 펄스 수가 어긋나고 왕복할수록 오차가 누적된다. wave는
보낼 펄스 수를 직접 지정하므로 스텝 수가 보장된다.

**아직 실제 하드웨어에서 검증하지 않았다.** 모터를 물린 뒤 `pulse_test.py`
부터 확인할 것.
