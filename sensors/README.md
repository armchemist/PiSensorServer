# 센서 (pH / 전도도)

라즈베리파이에는 ADC가 없어서 아날로그 센서를 직접 읽을 수 없다. 아두이노 우노가
아날로그를 읽어 USB 시리얼로 넘기고, 파이는 그 값을 받아 쓴다.

```
SEN0161 (pH)  ─┐
               ├─ 아두이노 우노 ──USB── 라즈베리파이
SEN0244 (TDS) ─┘
```

| 파일 | 역할 |
| --- | --- |
| `arduino_sensors/arduino_sensors.ino` | 우노에 업로드. JSON 한 줄씩 시리얼 출력 |
| `read_sensors.py` | 파이에서 실행. 시리얼을 읽어 출력/CSV 기록 |

## 배선

두 센서 모두 DFRobot Gravity 3핀이다. 케이블 색은 **빨강 = VCC, 검정 = GND,
파랑(또는 초록) = 신호**.

| 센서 | 신호 | VCC | GND |
| --- | --- | --- | --- |
| SEN0161 (pH) | `A0` | `5V` | `GND` |
| SEN0244 (TDS) | `A1` | `5V` | `GND` |

우노에는 `5V` 핀이 하나뿐이라 둘을 같이 물리려면 브레드보드로 나눠야 한다.
`GND` 는 우노에 여러 개 있어서 각각 꽂으면 된다.

⚠️ pH 프로브의 BNC 커넥터와 변환 보드는 **물에 닿으면 안 된다.** 물에 들어가는
것은 유리 전극 부분뿐이다.

⚠️ pH 프로브는 마르면 망가진다. 쓰지 않을 때는 보관액(KCl)에 담가둔다.

## 업로드

Arduino IDE에서 `arduino_sensors/arduino_sensors.ino` 를 열고
보드 `Arduino Uno`, 포트를 선택해 업로드한다. 맥에서 업로드한 뒤 USB 케이블만
파이로 옮겨 꽂아도 된다.

## 파이에서 실행

```bash
sudo apt install -y python3-serial
sudo usermod -aG dialout $USER      # 권한 오류가 나면. 실행 후 재로그인 필요

python3 read_sensors.py
python3 read_sensors.py --csv log.csv        # CSV로도 기록
```

출력:

```
포트: /dev/ttyACM0  (Ctrl+C로 종료)
14:22:01  pH  7.02 (2.506V)   EC   412.3 uS/cm   TDS   206.2 ppm
```

## pH 캘리브레이션

### 현재 상태 — 임시 1점 보정 (2026-08-16)

표준액이 없어서 **수돗물을 pH 7.00 으로 가정**하고 절편만 맞춰 두었다.

| 상수 | 값 | 근거 |
| --- | --- | --- |
| `PH_SLOPE` | `3.5` | **미검증.** 이론값 |
| `PH_INTERCEPT` | `0.268` | 수돗물 실측 1.9233V → 7.00 |

이 상태의 한계를 알고 쓸 것.

- **기준값 7.00 자체가 부정확하다.** 수돗물은 완충 용액이 아니라 지역·시간·수온에
  따라 6.5~8.5 로 변하고, 공기 중 CO2 를 흡수하며 서서히 산성화된다
- **기울기를 검증하지 않았다.** 1점 보정은 기준점 근처에서만 맞는다. 기울기가
  10% 틀렸다면 pH 6 이나 8 에서 약 0.1 의 오차가 생긴다
- 상대적인 변화 추이를 보는 데는 쓸 수 있지만, **실험 데이터로 기록할 값은 아니다**

### 2점 보정 (표준액 확보 후 반드시 할 것)

pH 4.00 / 7.00 표준액으로 보정한다.

1. 스케치를 업로드하고 `read_sensors.py` 를 실행해 `ph_v`(전압)를 본다
2. 프로브를 증류수로 헹군 뒤 **pH 7.00 표준액**에 담근다.
   값이 안정될 때까지 1분쯤 기다렸다가 전압을 적는다 → `V7`
3. 다시 헹군 뒤 **pH 4.00 표준액**에서 같은 방법으로 → `V4`
4. 기울기와 절편을 계산한다

   ```
   PH_SLOPE     = (7.00 - 4.00) / (V7 - V4)
   PH_INTERCEPT = 7.00 - PH_SLOPE * V7
   ```

5. `arduino_sensors.ino` 의 두 상수를 고쳐 다시 업로드한다

프로브는 시간이 지나면 특성이 변하므로 주기적으로 다시 보정해야 한다.

## 알아둘 점

**수온 보정** — pH와 전도도 둘 다 수온에 민감하다. 지금은 `WATER_TEMP_C = 25.0`
으로 고정해 뒀다. 정확한 값이 필요하면 DS18B20 방수 온도센서를 붙이고 실측값을
쓰는 게 좋다. 이건 디지털(1-Wire)이라 파이에 직접 붙일 수도 있다.

**두 프로브 간 간섭** — pH와 TDS 프로브를 같은 물에 함께 담그면 서로 간섭해서
값이 흔들릴 수 있다. 알려진 현상이다. 값이 불안정하면 한 번에 하나씩 담가
확인해 보고, 그래도 필요하면 TDS 모듈 전원을 디지털 핀으로 제어해 번갈아
측정하는 방식으로 바꾼다.

**TDS 절대값** — `SEN0244` 의 3차식은 공장 표준 기준이라 절대값은 오차가 있다.
정밀한 값이 필요하면 1413µS/cm(또는 707ppm) 표준액으로 따로 보정해야 한다.
상대적인 변화 추이를 보는 용도로는 그대로 써도 된다.

다만 **전도도에서 지금 가장 큰 오차원은 3차식이 아니라 수온이다.** 전도도는
수온 1도당 약 2% 변하는데 `WATER_TEMP_C = 25.0` 으로 고정돼 있다. 수온이 20도면
그것만으로 10% 어긋난다. 보정 순서는 **수온 실측 → 표준액** 이 맞다.

## 프로브 보관

두 프로브의 요구가 **정반대**라 헷갈리기 쉽다.

| | pH (SEN0161) | 전도도 (SEN0244) |
| --- | --- | --- |
| 보관 | **젖은 상태 유지** (KCl 보관액) | **헹궈서 말린다** |
| 마르면 | 유리막 손상 → 프로브 사망 | 문제 없음 |

⚠️ **TDS 프로브를 pH 보관액에 담그지 말 것.** KCl 은 고농도 염 용액이라 전극에
염분이 남아 이후 측정값이 크게 틀어진다.

- 사용 후 증류수로 헹군다. 시료가 마르면서 생긴 피막이 쌓이면 전도도가 서서히
  낮게 나오는데, 천천히 변해서 알아채기 어렵다
- 프로브 헤드는 방수지만 **케이블 접합부는 아니다.** 잠기는 깊이를 제한할 것
- 강산·강염기를 잰 뒤에는 즉시 헹군다. 전극이 부식된다
- 측정 범위는 0~1000ppm. 기포가 붙으면 값이 튀므로 담근 뒤 살짝 흔들어 털어낸다
